# Networking Fundamentals from an infrastructure perspective

LAN, WAN, VLANs, subnetting and firewalls: a knowledge portfolio.

**Read it as a website:** https://jsephfwleroo947-hub.github.io/networking-fundamentals/

This project explains how core networking building blocks work and how they fit together, and shows the understanding through explanation, worked subnetting problems, firewall rule design and fault diagnosis, with diagrams drawn for the project.

**Author:** Joseph | **Version:** 0.1 | **Date:** 16/10/2026

> All IP addresses, hostnames and organisations used in examples are fictional, and the scenarios are written for learning purposes.

## Contents

1. [About this project](https://jsephfwleroo947-hub.github.io/networking-fundamentals/01-about-this-project.html): Purpose, scope, how it was learned, and key terms
2. [LAN vs WAN](https://jsephfwleroo947-hub.github.io/networking-fundamentals/02-lan-vs-wan.html): Ownership, scale and devices, and where the OSI model fits
3. [VLANs vs subnets](https://jsephfwleroo947-hub.github.io/networking-fundamentals/03-vlans-vs-subnets.html): Layer 2 vs Layer 3, why they are paired, and inter-VLAN routing
4. [Subnetting](https://jsephfwleroo947-hub.github.io/networking-fundamentals/04-subnetting.html): Binary, CIDR, host counts, VLSM, worked problems and an addressing plan
5. [Firewalls](https://jsephfwleroo947-hub.github.io/networking-fundamentals/05-firewalls.html): Stateless vs stateful, core concepts, a rule table and rule-order effects
6. [Troubleshooting case studies](https://jsephfwleroo947-hub.github.io/networking-fundamentals/06-troubleshooting-case-studies.html): Four fault scenarios with symptoms, diagnosis, cause and fix
7. [Self-test](https://jsephfwleroo947-hub.github.io/networking-fundamentals/07-self-test.html): Ten questions with model answers
8. [Reflection](https://jsephfwleroo947-hub.github.io/networking-fundamentals/08-reflection.html): Mistakes made and what to explore next
9. [References](https://jsephfwleroo947-hub.github.io/networking-fundamentals/09-references.html): Sources
