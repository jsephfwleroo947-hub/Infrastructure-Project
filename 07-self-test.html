7. Self-test

# Question Model answer
1 What is the difference between a VLAN and a subnet? A VLAN works at Layer 2 and splits a switch into separate broadcast domains. A subnet works at Layer 3 and splits an IP address range into separate networks. They solve different problems, but each VLAN normally carries exactly one subnet so the two boundaries line up.
2 What is the difference between an access port and a trunk port? An access port belongs to one VLAN and connects an end device, with frames untagged. A trunk port connects switches, routers or firewalls and carries several VLANs over one link, with each frame tagged using 802.1Q.
3 How many usable host addresses are in a /27? A /27 has 5 host bits, so 2^5 - 2 = 30 usable addresses. Two are subtracted because the all-zeros address is the network address and the all-ones address is the broadcast address.
4 Find the network address, broadcast address and usable range for 192.168.10.100/26. The block size is 256 - 192 = 64, so subnets start at .0, .64, .128 and .192. The address .100 falls in the .64 subnet. Network: 192.168.10.64. Broadcast: 192.168.10.127. Usable range: 192.168.10.65 to 192.168.10.126.
5 Are 192.168.5.200 and 192.168.5.230 on the same subnet if the mask is 255.255.255.224? No. The block size is 256 - 224 = 32. The address .200 is in the subnet starting at .192 (range .192 to .223) and .230 is in the subnet starting at .224 (range .224 to .255). They are on different subnets, so traffic between them must go through a router.
6 What is the smallest subnet mask that can hold 60 hosts? 5 host bits give only 30 usable addresses, which is too few, and 6 host bits give 62, which is enough. That means a /26 (255.255.255.192).
7 Two PCs are plugged into the same switch but are in different VLANs. Can they ping each other? Why or why not? Not directly. They are in separate broadcast domains, so a Layer 2 switch will not pass traffic between them. They can only communicate if a Layer 3 device (a router or Layer 3 switch) routes between the two VLANs.
8 Why does a stateful firewall need fewer rules than a stateless one for the same job? A stateful firewall records connections in a state table, so replies to a connection started from the inside are allowed automatically. A stateless firewall treats every packet independently, so it needs a separate rule to allow return traffic, which usually means leaving wide port ranges open.
9 A firewall has a rule denying the DMZ access to the internal network, placed above a rule allowing the web server to reach the database on TCP 5432. What happens, and what is the fix? The firewall uses first-match processing, so database traffic matches the broad deny first and the allow rule below it is never reached (a shadowed rule). The website works, but any page needing data fails. The fix is to move the specific allow above the broad deny.
10 Why are public-facing servers placed in a DMZ rather than on the internal network? They are the most exposed systems and the most likely to be compromised. In a separate segment, firewall rules can limit what they reach inwards (for example, one database port), so an attacker who takes over a DMZ server cannot scan or move into the internal networks.
